# Imágenes

Capturas de pantalla, wireframes, mockups y bocetos referenciados desde el portafolio.

Se centralizan acá para no duplicar archivos entre las carpetas de cada unidad.

> Nota: la carpeta `images/` de la raíz del repositorio está en `.gitignore` y es material de
> trabajo local. Las imágenes que forman parte de la documentación van en esta carpeta.
