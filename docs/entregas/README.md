## Sobre los archivos originales

Los `.docx` y `.pdf` **no se versionan** (están en `.gitignore`): lo que sube al repositorio es
su conversión a Markdown, para que GitHub la renderice y `git diff` muestre qué cambió entre
versiones. Los originales quedan en la carpeta local de la cursada.

Si en algún momento el equipo decide subir los PDF finales tal como se entregaron, alcanza con
agregar una excepción al final de `.gitignore`:

```gitignore
!docs/entregas/*.pdf
```
